# Industrial Motion

这是一个只操作内存状态的虚拟轴动作执行框架，不连接或控制真实机器。当前版本面向单轴，轨迹采用有限速度和有限加速度的分段恒加速度模型，后续多轴协调可以复用相同的动作状态与生命周期。

## 生命周期

- `EnqueueMove`：动作进入队列；队列只包含等待项，当前运行项单独保存。
- `SetTarget`：从控制器当前真实位置和速度立即生成新轨迹，中断当前动作并取消等待队列，不会从旧目标的起点重放。
- `CancelQueued`：只取消尚未运行的动作，不改变当前动作。
- `SoftStop`：按最大加速度减速到零；减速完成前保持 `soft_stopping`，完成后进入 `soft_stopped`，等待队列保留。
- `Resume`：软停止后继续执行保留的等待队列。
- `EmergencyStop`：立即清零速度、停止当前动作并取消等待队列，之后必须 `Reset`。
- `Snapshot` / `RestoreController`：保存位置、速度、模式、动作状态和未完成轨迹；未到位动作不会被标记为完成。

控制器由外部时钟调用 `Tick(dt)` 推进，便于测试和未来扩展到确定性多轴调度。

## 验证

```bash
go test -race ./...
go vet ./...
```

测试会密集采样短距离、反向和中途改目标轨迹，检查速度、加速度、位置/速度连续性以及最终状态，而不只检查终点。
